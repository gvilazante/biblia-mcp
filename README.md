# biblia-mcp

MCP para leitura e reflexão bíblica.

A ferramenta `biblia` recebe uma referência bíblica, passagem, capítulo,
versículo ou sentimento e aplica instruções estruturadas para apresentar
o texto bíblico, seu contexto e uma reflexão relacionada à experiência
humana.

## Ferramenta

### `biblia`

Recebe uma entrada textual.

Exemplo:

```text
biblia("Mateus 12,1:5")
